# DeviceNexus

### Device & Customer Management Dashboard

DeviceNexus is a React-based **admin dashboard** designed to manage customers, devices, service requests, warranty information, and related data from one centralized platform.

## 🚀 Features

- 📊 Admin Dashboard
- 👥 Customer Management
- 💻 Device Management
- 🛠️ Service Requests
- 📄 Warranty Information
- 👤 Profile & Profile Dropdown
- ⚙️ Interactive Settings
- 🌙 Light & Dark Theme
- 📱 Responsive UI
- 🧩 Reusable React Components
- 🧭 React Router Navigation

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- React
- React Router
- Vite
- Git & GitHub

## 📌 Current Phase

**Phase 1 – Admin Dashboard**

The current version is a frontend implementation using **static/mock data**. Backend, database, and authentication are not yet implemented.

## 🔮 Future Scope

Future versions will include:

- Backend & database integration
- Authentication & authorization
- Customer dashboard
- Customer-specific data access
- Real-time/persistent data

### 👥 Project

DeviceNexus is developed as a team-based academic project using Git and GitHub for collaboration and version control.
